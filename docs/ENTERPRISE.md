# 企业佣金与销售激励管理系统企业能力

## 领域覆盖

- **激励方案**：配置适用期间、产品、区域、角色、阶梯和封顶规则
- **资格管理**：维护人员、岗位、在职状态和方案适用资格
- **目标管理**：分解收入、毛利、回款、产品和战略目标
- **业绩归属**：归集订单、回款、退款并处理拆分与归属争议
- **佣金计算**：按规则版本计算阶梯、加速、奖金、封顶和扣减
- **调整申诉**：管理补发、扣回、人工调整、证据和申诉
- **结果复核**：执行经理、财务、人力和合规多级复核
- **发放管理**：生成发放批次并对接薪资、应付或渠道结算
- **追索审计**：对退单、坏账和违规交易执行追索并保留证据

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业佣金与销售激励管理系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `CRM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
